FKL Central and admin

Master data for every hub. From the Workshop App to KART.

Steps

  1. Select your Hub > FKL Central.
  2. Parts catalogue > Master parts: search, Add part (MPN required), Edit part (pencil), Suppliers.
  3. Catalogues: New catalogue, add parts, then set its exact Kart generation. Hub catalogues: what each hub sees.
  4. Part requests > Review: Link part, Add part, Keep local or Reject request.
  5. Master review: check hub-local parts, merge into a master part.
  6. Service checklists: choose the class, New draft, open a section, Add check.
  7. Check before publishing says No errors? Publish with What changed (required).
  8. Servicing: tyre tread, alignment, battery voltage, axle run-out. Each box has its own Save.
  9. Admins: Admin Access > User Administration > All Users.
  10. Set Hub Access and Permissions; save each.
  11. Deactivate user with a reason is a soft switch-off; Reactivate user undoes it.
RememberYour hub lead and FKL Central agree new parts. Hub managers can give only Workshop and Purchasing.
Watch outPublishing a checklist changes it for every hub with that kart class from the next service. Tell the hub managers first.
