# Direct chats

:::defaults
persona: Alex Mechanic
device: tablet
url: /comms
state: "Existing direct chat between Alex Mechanic and Casey Mechanic"
:::

Any staff member can start a direct chat with any colleague in KART Comms. It is a quick way to ask the other shift a question or share a photo.

!!! info "What changed from the Workshop App"
    - **New direct chats are private to the two people in them.** Remote support and admins do not see them.
    - **Existing chats keep their visibility.** A chat that existed before stays as visible as it was.
    - **Starting a chat with someone you have chatted with before reopens that same chat.**
    - Notifications show names or initials, never e-mail addresses.

1. In KART Comms, find **Direct Chats**. Tap the search box for a new direct chat.

    :::shot rs-direct-list
    caption: Direct Chats with the new direct chat search box
    steps:
      - Open /comms
    callouts:
      - [1, "text=Direct Chats", "Your direct chats"]
      - [2, "css=input[placeholder^='New direct chat']", "Find a colleague"]
    :::

2. Type part of the name or the initials, for example "Ca" or "CM".

    :::shot rs-direct-search
    caption: Casey Mechanic found by typing Ca
    steps:
      - Type Ca
    callouts:
      - [1, "text=Casey Mechanic", "Tap to chat"]
    :::

3. Tap the colleague. If you chatted before, the same chat opens again.

    :::shot rs-direct-open
    caption: The existing chat between Alex and Casey
    steps:
      - Tap Casey Mechanic
    callouts:
      - [1, "text=Casey Mechanic", "The same chat as before"]
    :::

4. Type your message and tap **Send**. Use **Attach file** for a photo.

    :::shot rs-direct-send
    caption: A message typed in the direct chat with Send and Attach file
    steps:
      - Type "Can you check the 205 chain before you go?" and tap Send
    callouts:
      - [1, "text=Send", "Send"]
      - [2, "css=button[aria-label='Attach file']", "Add a photo"]
    :::

## For remote support

1. In the Support view, tap **Start a direct chat** to message a staff member directly.

    :::shot rs-direct-support
    caption: Start a direct chat in the Support view
    persona: Riley Support
    device: desktop
    steps:
      - Open /comms as Riley Support
    callouts:
      - [1, "text=Start a direct chat", "Message a staff member"]
    :::

!!! note "Remember"
    You cannot see new private direct chats between two colleagues, even as remote support or admin. That is by design.

!!! tip "Tip"
    In a chat, type **@** and two letters to mention a colleague. KART lists names and initials only.
