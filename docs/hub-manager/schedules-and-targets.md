# Schedules and targets


This page covers three things: how your hub's weekly schedule works (**Schedule settings**), targets for each person (**Work targets**) and how many karts each class must have ready for an event (**Readiness targets**).

!!! info "What changed from the Workshop App"
    - **Schedule Settings** is now **Schedule settings** on the Schedule tab.
    - **Workshop Planning** is now two Workshop Manager tabs: **Work targets** and **Readiness targets**.
    - Readiness targets are set per **planning event**. Admins create planning events for now.

## Schedule settings

1. Open **Schedule** and tap **Schedule settings**.

    ![Schedule settings with participants and scheduling mode](../assets/img/hub-manager/hm-sched-settings.png){ loading=lazy }

2. Choose the **Scheduling mode**: **Employee planned** (mechanics plan their own week) or **Manager assigned** (you plan it).

    ![Scheduling mode Employee planned or Manager assigned](../assets/img/hub-manager/hm-sched-mode.png){ loading=lazy }

3. Set the **Submission deadline day** and the time.

    ![Submission deadline day Friday and the time](../assets/img/hub-manager/hm-sched-deadline.png){ loading=lazy }

4. Tick **Require start time** and **Require finish time** if you need them.

    ![Require start time and Require finish time ticked](../assets/img/hub-manager/hm-sched-require.png){ loading=lazy }

5. Under **Schedule participants**, tick who is included and whether they may work remotely (**Allow remote work**).

    ![Schedule participants with Allow remote work](../assets/img/hub-manager/hm-sched-people.png){ loading=lazy }

6. Tap **Save settings**.

    ![The Save settings button](../assets/img/hub-manager/hm-sched-save.png){ loading=lazy }

## Work targets

1. Open **Workshop Manager > Work targets** and tap **Add target**.

    ![Work targets with the Add target button](../assets/img/hub-manager/hm-target-add.png){ loading=lazy }

2. Choose the **Person** and the **Work type**: Readiness, Turns, Repairs or Campaign tasks.

    ![Person Alex Mechanic and Work type Turns](../assets/img/hub-manager/hm-target-type.png){ loading=lazy }

3. Type the target number, optionally a class and a note.

    ![Target (completed) set to 10 for Cadet](../assets/img/hub-manager/hm-target-number.png){ loading=lazy }

4. Tap **Save target**. The target shows on the mechanic's **Work targets** card on Overview.

    ![The saved target in the Work targets list](../assets/img/hub-manager/hm-target-save.png){ loading=lazy }

!!! tip "Tip"
    Old targets move to **Archived targets**, so the list stays short.

## Readiness targets

1. Open **Workshop Manager > Readiness targets**. Find the planning event, for example **Demo Regional Race**.

    ![Readiness targets with Demo Regional Race](../assets/img/hub-manager/hm-ready-list.png){ loading=lazy }

2. Tap **Set target** (or **Edit target**) for the event.

    ![Edit target for Demo Regional Race](../assets/img/hub-manager/hm-ready-edit.png){ loading=lazy }

3. Type how many event-usable karts each class needs. Use whole numbers from 0 to 1000.

    ![Bambino, Cadet and Junior numbers for Demo Regional Race](../assets/img/hub-manager/hm-ready-numbers.png){ loading=lazy }

4. Save. Overview's **Event readiness** card shows **Target met** or **Remaining** for each class.

    ![Event readiness on Overview showing Remaining per class](../assets/img/hub-manager/hm-ready-overview.png){ loading=lazy }
